# Progress - Step by Step Pipeline (snpEff -> SnpSift TSV -> XGBoost [+ DNABERT])

This doc is a detailed, copy pasteable guide to go from per‑sample **SnpEff→SnpSift TSVs** to **per‑drug resistance classifiers**. It includes minimal annotation instructions (with common pitfalls), feature construction, lineage‑aware evaluation, and optional extensions (catalogue features, DNABERT, SHAP).

---

## 0) Inputs & Outputs (at a glance)

**You have (per sample):** a TSV with columns like
```
CHROM, POS, REF, ALT,
ANN[*].EFFECT, ANN[*].IMPACT, ANN[*].GENE, ANN[*].GENEID,
ANN[*].HGVS_C, ANN[*].HGVS_P, ANN[*].FEATURE, ANN[*].FEATUREID, ANN[*].BIOTYPE
```
> These come from `SnpSift extractFields` with `-s ","`.

**You also have:**
- `meta_raw.csv` with `accession,lineage,Phenotype_Isoniazid,...,phen_inh,phen_rif,phen_emb,phen_pza` where `R/S` or `1/0` denote resistance/susceptibility.
- (Optional) WHO/TB catalogue list as `who_catalog_mutkeys.csv` (columns at least: `mut_key`, optionally `drug,category`).

**We will produce:**
- `all_samples_mutkeys.csv` (long format: `sample_id,mut_key`)
- `variant_presence_matrix.csv` (wide binary matrix: isolates × mutation keys)
- `meta_labels.csv` (aligned meta with numeric labels per drug + lineage)
- `features_with_lineage.csv` (features + lineage one‑hots)
- Cross‑validated metrics per drug from XGBoost

## 1) (If needed) Stable Annotation & Extraction

> If you already have good TSVs, skip to §2. Keep this for troubleshooting.

**Contig names must match the snpEff DB.** For MTB H37Rv, snpEff’s public DB often uses `Chromosome` while many VCFs use `NC_000962.3`. If you see `ERROR_CHROMOSOME_NOT_FOUND` in `ANN=`, rename the contig in the VCF **before** annotating.

**Non‑piped, file‑by‑file steps:**

```bash
# 0) (optional) rename contigs to match snpEff DB (example NC_000962.3 -> Chromosome)
printf "NC_000962.3 Chromosome\n" > chr.map
bcftools annotate --rename-chrs chr.map -O v -o ERR2512812.renamed.vcf ERR2512812.raw.vcf

# 1) snpEff with HGVS tokens
java -Xmx8g -jar snpEff/snpEff.jar -hgvs Mycobacterium_tuberculosis_h37rv \
  ERR2512812.renamed.vcf -v > ERR2512812.ann.vcf

# 2) optional: filter with SnpSift (safer expression accepts FILTER='.' and requires ANN)
java -Xmx2g -jar snpEff/SnpSift.jar filter \
  "( ( FILTER = 'PASS' ) | ( FILTER = '.' ) | ( ! exists FILTER ) ) & ( QUAL >= 30 ) & ( exists ANN )" \
  ERR2512812.ann.vcf > ERR2512812.ann.pass.vcf

# 3) extract ANN fields (note: FEATUREID not FEATURE_ID)
java -Xmx2g -jar snpEff/SnpSift.jar extractFields -s "," \
  ERR2512812.ann.pass.vcf \
  CHROM POS REF ALT \
  "ANN[*].EFFECT" "ANN[*].IMPACT" "ANN[*].GENE" "ANN[*].GENEID" \
  "ANN[*].HGVS_C" "ANN[*].HGVS_P" "ANN[*].FEATURE" "ANN[*].FEATUREID" "ANN[*].BIOTYPE" \
  > ERR2512812.ann.pass.tsv
```

**Sanity checks:**
- `grep '^##INFO=<ID=ANN' ERR...ann.vcf` shows the ANN header.
- First variant lines do **not** end with `ERROR_CHROMOSOME_NOT_FOUND`.
- `HGVS_C/HGVS_P` present if `-hgvs` is used.

## 2) Build Canonical Mutation Keys (per sample)

We collapse each variant’s multiple ANN entries to a **single canonical key** per ALT. This stabilizes feature names across isolates.

**Key rules (recommended):**
- Nonsyn/stop/frameshift: `GENE|p.Ser315Thr` (from `HGVS_P`)
- Synonymous: `GENE|syn:c.123A>G` (from `HGVS_C`)
- Promoter/regulatory/upstream/downstream: `GENE|promoter:POSREF>ALT`
- Intergenic: `intergenic|CHROM:POS:REF>ALT`
- Fallback: `GENE|EFFECT:POSREF>ALT`

**Effect priority** (choose one ANN per site):
```
stop_gained > stop_lost > start_lost > frameshift_variant >
missense_variant > synonymous_variant >
splice_(acceptor|donor|region)_variant >
upstream/downstream/regulatory > intergenic_region
```

**Script:** `build_mutkeys.py` (drop in project root) — it:
- reads TSVs, parses `ANN[*]` lists
- picks the best annotation per site
- emits unique `mut_key`s per sample into `all_samples_mutkeys.csv`

```python
import pandas as pd, pathlib, re

EFFECT_PRIORITY = [
    "stop_gained", "stop_lost", "start_lost", "frameshift_variant",
    "missense_variant", "synonymous_variant",
    "splice_acceptor_variant", "splice_donor_variant", "splice_region_variant",
    "upstream_gene_variant", "downstream_gene_variant", "regulatory_region_variant",
    "intergenic_region"
]

def best_ann(effects):
    for eff in EFFECT_PRIORITY:
        for i, e in enumerate(effects):
            if eff in e:
                return i
    return 0 if effects else None

def parse_csv(tsv_path: pathlib.Path):
    df = pd.read_csv(tsv_path, sep="\t", dtype=str).fillna("")
    colmap = {
        "ANN[*].EFFECT":"EFFECTS","ANN[*].IMPACT":"IMPACTS","ANN[*].GENE":"GENES","ANN[*].GENEID":"GENEIDS",
        "ANN[*].HGVS_C":"HGVS_C","ANN[*].HGVS_P":"HGVS_P","ANN[*].FEATURE":"FEATURES",
        "ANN[*].FEATUREID":"FEATUREIDS","ANN[*].BIOTYPE":"BIOTYPES"
    }
    df = df.rename(columns=colmap)
    mutkeys = []
    for _, r in df.iterrows():
        effects  = [x.strip() for x in r.get("EFFECTS","" ).split(",") if x!=""]
        genes    = [x.strip() for x in r.get("GENES",""   ).split(",") if x!=""]
        hgvsc    = [x.strip() for x in r.get("HGVS_C",""  ).split(",") if x!=""]
        hgvspt   = [x.strip() for x in r.get("HGVS_P",""  ).split(",") if x!=""]
        L = max(len(effects), len(genes), len(hgvsc), len(hgvspt), 1)
        while len(effects) < L: effects.append("")
        while len(genes)   < L: genes.append("")
        while len(hgvsc)   < L: hgvsc.append("")
        while len(hgvspt)  < L: hgvspt.append("")
        idx = best_ann(effects)
        if idx is None:
            continue
        eff  = effects[idx]
        gene = genes[idx] or "intergenic"
        c = hgvsc[idx].replace("c.","") if hgvsc[idx] else ""
        p = hgvspt[idx].replace("p.","") if hgvspt[idx] else ""
        chrom, pos, ref, alt = r["CHROM"], r["POS"], r["REF"], r["ALT"]
        refalt = f"{pos}{ref}>{alt}"
        if any(x in eff for x in ["missense_variant","stop_gained","stop_lost","start_lost","frameshift_variant"]):
            key = f"{gene}|p.{p}" if p else f"{gene}|{refalt}"
        elif "synonymous_variant" in eff:
            key = f"{gene}|syn:{c}" if c else f"{gene}|syn:{refalt}"
        elif any(x in eff for x in ["upstream_gene_variant","downstream_gene_variant","regulatory_region_variant"]):
            key = f"{gene}|promoter:{refalt}"
        elif "intergenic_region" in eff or gene == "intergenic":
            key = f"intergenic|{chrom}:{refalt}"
        else:
            key = f"{gene}|{eff}:{refalt}"
        mutkeys.append(key)
    return sorted(set(mutkeys))

if __name__ == "__main__":
    import argparse
    ap = argparse.ArgumentParser()
    ap.add_argument("--in_dir", required=True, help="folder with per-sample TSVs (use '.' for current)")
    ap.add_argument("--pattern", default="*.tsv", help="glob for TSV files")
    ap.add_argument("--out_pairs", default="all_samples_mutkeys.csv")
    args = ap.parse_args()

    rows = []
    for tsv in pathlib.Path(args.in_dir).glob(args.pattern):
        sample_id = tsv.stem
        sample_id = re.sub(r"\.ann(\.pass)?$", "", sample_id)  # normalize common suffixes
        mk = parse_csv(tsv)
        rows.extend([{ "sample_id": sample_id, "mut_key": k }] for k in mk)

    pd.DataFrame(rows).to_csv(args.out_pairs, index=False)
    print(f"Wrote {args.out_pairs} with {len(rows)} rows.")
```

**Run (TSVs in current directory):**
```bash

```

## 4) Prepare Labels & Lineage

We map phenotypes to numeric labels per drug (1=Resistant, 0=Susceptible), prefer `phen_*` numeric columns, and fall back to `Phenotype_*` (R/S) if needed. We also keep lineage for grouping.

```python
# make_labels.py
import pandas as pd
X = pd.read_csv("variant_presence_matrix.csv", index_col=0)
meta = pd.read_csv("meta_raw.csv")
meta = meta.rename(columns={"accession":"sample_id"}).set_index("sample_id")

def map_str(col):
    return col.map({"R":1, "S":0}).astype("Int64")

labels = pd.DataFrame(index=meta.index)
labels["label_INH"] = meta.get("phen_inh")
if labels["label_INH"].isnull().any() and "Phenotype_Isoniazid" in meta:
    labels["label_INH"] = labels["label_INH"].fillna(map_str(meta["Phenotype_Isoniazid"]))
labels["label_RIF"] = meta.get("phen_rif")
if labels["label_RIF"].isnull().any() and "Phenotype_Rifampicin" in meta:
    labels["label_RIF"] = labels["label_RIF"].fillna(map_str(meta["Phenotype_Rifampicin"]))
labels["label_EMB"] = meta.get("phen_emb")
if labels["label_EMB"].isnull().any() and "Phenotype_Ethambutol" in meta:
    labels["label_EMB"] = labels["label_EMB"].fillna(map_str(meta["Phenotype_Ethambutol"]))
labels["label_PZA"] = meta.get("phen_pza")
if labels["label_PZA"].isnull().any() and "Phenotype_Pyrazinamide" in meta:
    labels["label_PZA"] = labels["label_PZA"].fillna(map_str(meta["Phenotype_Pyrazinamide"]))

lineage = meta["lineage"].astype(str)
labels = labels.loc[X.index.intersection(labels.index)]
lineage = lineage.loc[labels.index]
clean = pd.concat([lineage.rename("lineage"), labels], axis=1)
clean.to_csv("meta_labels.csv")
print("Wrote meta_labels.csv:", clean.shape)
```

## 6) Train Per‑Drug XGBoost (Lineage‑Grouped CV + Calibration)

We train **one model per drug**, grouping folds by lineage to control population structure. We calibrate probabilities (isotonic) for thresholding.

```python
# train_per_drug.py
import numpy as np, pandas as pd
from xgboost import XGBClassifier
from sklearn.model_selection import GroupKFold
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import roc_auc_score, average_precision_score

X = pd.read_csv("features_with_lineage.csv", index_col=0)
meta = pd.read_csv("meta_labels.csv", index_col=0)
groups = meta["lineage"].astype(str).values

def train_one(drug):
    y = meta[f"label_{drug}"]
    keep = ~y.isna()
    y = y[keep].astype(int).values
    Xd = X.loc[keep]
    gd = groups[keep]
    if y.sum() == 0 or y.sum() == len(y):
        print(f"{drug}: skipped (single‑class labels)")
        return None
    gkf = GroupKFold(n_splits=5)
    aucs, auprcs = [], []
    for tr, te in gkf.split(Xd, y, gd):
        base = XGBClassifier(
            n_estimators=600, max_depth=6, subsample=0.8, colsample_bytree=0.8,
            reg_lambda=1.0, learning_rate=0.05, n_jobs=-1, eval_metric='logloss',
            scale_pos_weight=max(1.0, (y[tr]==0).sum()/max(1,(y[tr]==1).sum()))
        )
        model = CalibratedClassifierCV(base, cv=3, method="isotonic")
        model.fit(Xd.iloc[tr], y[tr])
        p = model.predict_proba(Xd.iloc[te])[:,1]
        aucs.append(roc_auc_score(y[te], p))
        auprcs.append(average_precision_score(y[te], p))
    return np.mean(aucs), np.mean(auprcs)

for drug in ["INH","RIF","EMB","PZA"]:
    res = train_one(drug)
    if res:
        auc, auprc = res
        print(f"{drug}\tAUROC={auc:.3f}\tAUPRC={auprc:.3f}")
```

## 7) Threshold Selection & Clinical Metrics

Clinical use prioritizes minimizing **Very Major Errors (VME = false susceptible)**. After CV, choose per‑drug thresholds on held‑out folds to reduce VME at acceptable **Major Error (ME = false resistant)**.

Example helper:
```python
import numpy as np
from sklearn.metrics import confusion_matrix

def pick_threshold_min_vme(y_true, p):
    best_thr, best_vme = None, 1e9
    for thr in np.linspace(0.05, 0.95, 181):
        yhat = (p >= thr).astype(int)
        tn, fp, fn, tp = confusion_matrix(y_true, yhat).ravel()
        vme = fn
        if vme < best_vme:
            best_thr, best_vme = thr, vme
    return best_thr
```

**Report (per drug):** Sensitivity, Specificity, AUROC, AUPRC, VME, ME, and the chosen threshold.

## 9) Extensions & Iteration

- **Start with catalogue mutations** (WHO categories 1/2) for a strong baseline; then add the long tail of non‑catalogue `mut_key`s.
- **Heteroresistance signals:** include allele fraction / alt depth (AF, AD[1]) if available from your caller.
- **Promoter distance:** parse `ANN[...].DISTANCE` and encode bins (e.g., −10/−35 regions) for regulatory variants.
- **Gene‑level aggregates:** counts of impactful mutations per gene (pncA, embB, rrs, etc.).
- **DNABERT track (hybrid):** extract ±100–200 bp windows around each mutation (apply ALT), embed with DNABERT (frozen), mean‑pool per mutation, then average/attention‑pool per sample and **concatenate** to the tabular features before XGBoost.
- **External validation:** evaluate on public sets (e.g., CRyPTIC‑like) or compare against TB‑Profiler/Mykrobe calls as baselines.

## 10) Common Pitfalls & Fixes

- **`ERROR_CHROMOSOME_NOT_FOUND` in ANN** → contig name mismatch; rename VCF contigs or build a custom snpEff DB using the same FASTA/GFF.
- **Empty TSV after filter** → your VCF may have `FILTER='.'`; use the safer filter expression in §1.
- **Missing `FEATUREID` error** → use SnpSift fields `FEATUREID` (no underscore), `GENEID`, etc.
- **`No such FORMAT field: DP`** → adjust filters to tags that exist in your VCF (e.g., use `INFO.DP/AF` or `GEN[0].AD[1]`). Probe with `##FORMAT`/`##INFO` headers or `SnpSift extractFields CHROM POS INFO`.
- **BGZF index failure** → happens if a previous step errored and wrote a truncated gz file; re‑run the failing step, ensure `-Oz` (bgzip) was successful.
- **Windows environments** → prefer WSL2/Ubuntu or Docker images for `bcftools/tabix`; Java jars (snpEff/SnpSift) run natively.
